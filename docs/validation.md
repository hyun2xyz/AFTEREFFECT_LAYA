# 검증 범위

2026-10-26 KST. 소스 검사, 준비 도구, 실제 Adobe 앱 확인을 구분한다.

## 이번 저장소의 준비 경로

- Python3.13.2에서 회귀 검사46개를 통과했다. 경로/입력/대상/읽기 결과/애니메이션
  보호와 프로젝트 환경 준비, 백업·복원·기존 명령 보존을 포함한다.
- Git 없는 별도 복사 폴더에서 pip 없는 새 `.venv`를 만들었다. pip, Laya, Torch,
  Pillow가 없는 상태에서 한글 명령 미리보기와 선택 실행기를 실제로 실행했다.
- `--check`는 변경하지 않으며, `--configure`는 검증 후 로컬 경로만 저장한다.
  준비 완료나 경로 탐지는 라이선스·AE 버전·실제 실행의 합격이 아니다.
- Windows처럼 레거시 인코딩인 파이프에서 한글 JSON이 실패하는 사례를 재현하고
  UTF-8 출력을 고정했다. 이 검사는 실제 subprocess의 한글 값을 대조한다.
- 실제 `comp 1920 1080` 같은 축약형이 예전 Laya-Mac의 시스템 상태 조회로 넘어가는
  실패를 확인해 AE 범위 분기와 숫자 문형을 추가했다. 미지원·부정·질문 요청은 앱을
  바꾸거나 시스템 상태 성공으로 우회하지 않는다. 명시적인 기존 앱 실행 요청은 보존한다.
- 새 학생의 문서 흐름을 별도로 검토했다. Python/AE 설치 전에 기본 실습이 이미
  가능한 것처럼 안내하지 않으며, Homebrew/Git/모델은 첫 실습의 필수 조건이 아니다.

[커밋별 CI](https://github.com/hyun2xyz/AFTEREFFECT_LAYA/actions)는 macOS/Windows ×
Python3.12/3.13에서 추가 패키지 없이 검사와 Git 없는 복사 폴더 준비/실행기 smoke를
실행한다. 각 커밋의 실제 결과를 확인한다. Windows CI는 AE 앱을 설치하거나 실행하지 않는다.

## 실제 After Effects

- 이 저장소의 새 `.venv`/경로 설정으로 Mac AE26.3x87에 native 조회를 실행했고,
  실제 버전·상태·readback을 확인했다. 기존 프로젝트를 저장·닫기·교체하지 않았다.
- 축약형 `comp 1920 1080`으로 실제1920×1080/30fps/10초 컴프를 생성했다.
  native 크기/컴프 ID를 대조하고 실제 AE 창의 새 `Laya AE` 항목까지 확인했다.
- 동일한 고정 JSX 코어는 이 Mac에서 실제 새1920×1090컴프, 초록 배경, text/null,
  이름/표시,2D/3D transform과 opacity keyframe을 실행해 요청 값과 대조했다.
- 첫 코어 batch에서2D getter가3성분을 반환해 멈춘 기록을 보존했고, 숨은 제3성분을
  유지하는2D 정규화로 미완료 조작만 이어 검증했다. 전체 batch를 중복 실행하지 않았다.
- stale snapshot은 변경 전에, 중복 job은 native 전달 전에 거부했다. 실제 프로젝트
  항목 수/활성 컴프 유지도 확인했다. undo group은 트랜잭션이라고 주장하지 않는다.
- 에이전트 샌드박스(Codex 등) 안에서는 Apple 이벤트와 `AfterFX.exe -r`이 막힐 수 있어,
  승인 후 샌드박스 밖 실행을 안내한다. Codex에서의 실제 승인 흐름은 미검증이다.
- Windows의 실제 AE 앱·완전한 빈 OS의 설치기 UI·모든 AE 버전은 미검증이다.
  새 호스트에서 학생이 첫 native 결과와 화면을 확인한다.

## 선택 Laya

- 기존 Mac의 Laya-MLX0.1.0과 로컬 다국어 모델로 짧은 합성 추론을 실행했다.
  한국어 dev4예시에서 작업 분류3/4,mode4/4였고 인용문 오분류 사례가 있었다.
  `19201090` 문장을 기권한 사례도 있어 고정 명령은 모델보다 규칙을 먼저 쓴다.
- 이는 독립 holdout 정확도·확률 보정·자동 실행 합격 기준이 아니다. 모델은 조언만 한다.
- 선택 문서의 새 venv/모델 다운로드 전 과정을 이번 저장소에서 재설치하지는 않았다.
  설치된 메타데이터와 공식 배포 출처를 대조했으며 raw snapshot/고지를 보존하도록 안내한다.
  모델과 런타임을 패키지에 포함하지 않는다. Windows/Intel Laya 추론은 미검증이다.
- 토큰 절감률과 전체 처리 시간의 비교 수치는 미측정이다. 지원 명령의 실제 기본 경로는
  `model_called: false`이며 별도 LLM/모델 호출을 만들지 않는다.
